# VoiceVault 🔐🎙️

free nicer voices for VoiceOver on iPhone, plus the old + new Google voices for NVDA on Windows. how to get them, samples u can play, and downloads with instructions.

**the site:** https://2three1y.github.io/VoiceVault/

## what's inside
- how to get Piper voices on ur iPhone (the free "Piper - Neural TTS" app, needs iOS 18 or later) so VoiceOver + Spoken Content can use them
- samples of the old Google voice (Android 4.0 era) and the new Google voice (Chrome's natural one)
- download zips with an Instructions doc for each
